# Externally-published modules folded into this catalog's index.json.
#
# Every module in this catalog is built HERE: they are git submodules
# under submodules/, and the "Release <module>" workflows build, sign and
# publish their .lgx into this repo's own releases. This file is empty
# because nothing needs the escape hatch yet.
#
# Use it when a module can't be built here. The release pipeline builds
# one module per metadata.json directory, so a repo whose modules live in
# subdirectories is fine (see submodules/muster/module) — but a module
# released from somewhere you don't control, or one that needs a build
# this catalog can't run, has to publish its own signed .lgx. This file
# lists those sources; the "Augment index" workflow folds their release
# assets into index.json after every "Rebuild index", so clients see them
# alongside the locally-built ones.
#
# Format — one entry per line, blank lines and `#` comments ignored:
#
#   owner/repo                 every .lgx asset in that repo's releases
#                              (drafts and the `index` tag are skipped)
#   https://…/foo-1.0.0.lgx    a single package at a fixed URL
#
# `owner/repo` is preferred: new versions published over there are picked
# up automatically, with no edit here.
#
# TRUST: index.py copies whatever signature is inside each .lgx. An
# external package is only trusted by Basecamp if it was signed with a
# key whose DID is listed under `trustedSigners` in logos-repo.json.
# Adding a source here whose signer you don't control means vouching for
# that key — don't.
